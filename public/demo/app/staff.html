Удалить из компании

Удалить сотрудника — из компании —?

Удаляется только связь «Пользователь — Компания». Если сотрудник состоит в других компаниях, доступ к ним сохранится.

Удалить из системы

Полностью удалить пользователя — из системы?

Пользователь будет удалён из всех компаний и потеряет доступ к сервису. Действие необратимо. Доступно только Руководительу.

Создание сотрудника

Одна запись = участие пользователя в одной компании с определённой ролью. Если пользователь уже есть в системе — создаётся новая связь, новый пользователь не создаётся.
