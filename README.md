# PhotoKontur — маркетинговый сайт, версия site-v2

## Запуск после распаковки архива

Установите Node.js 22.12 или новее. Откройте терминал в папке `site-v2` и выполните:

```powershell
npm install
npm run dev
```

Откройте http://127.0.0.1:4323/ . Для проверки сборки: `npm run build`, затем `npm run preview` (предварительно остановите сервер разработки).

Если установлен pnpm 11, можно использовать `pnpm install --frozen-lockfile`, `pnpm dev` и `pnpm build`. На Windows после установки зависимостей также можно запустить `start-site.cmd`.

Архив не содержит `node_modules`, `dist`, `.astro` и папку `qa`: зависимости, сборка и кэш создаются локально. Исходники, изображения, встроенное демо, конфигурация и файл зависимостей включены.

Статические страницы после сборки находятся в `dist/`. Раздавать их нужно по HTTP с поддержкой `index.html` в каталогах; `file://` не поддерживается. Домен ещё не утверждён, поэтому canonical не выдуман; noindex установлен намеренно для демонстрации. Перед публикацией подключить форму, юридические документы, домен/canonical/sitemap и снять noindex только после проверки контента.

Контент и ограничения: CONTENT_REQUIRED.md. Происхождение визуалов: ASSETS.md. Решение по стеку: ARCHITECTURE.md. Браузерная проверка: qa-report.md.

## Монохромная версия (site-v2, 05.10.2026)

Клон `output/site` для правок. Отличия от оригинала:

- **Монохром.** Все цвета в `src` переведены в серые той же светлоты (скрипт `work/site-v2-monochrome.py`, Rec. 709). Фирменные токены в `src/styles/tokens.css` заданы вручную: акцент `--orange` → `#5f5f5f`, `--steel` → `#555`, `--sky` → `#d6d6d6`, фон `#f2f2f2`, текст `#141414`.
- **Без сгенерированных изображений.** Фото и фоны (первый экран, распознавание лиц, истории студий, эквайринг, обложки и фото в журнале, заявка, кейс) заменены блоками-заглушками `.ph` из `src/styles/global.css` — серый прямоугольник с диагоналями и подписью, что здесь будет. Лица в анимации распознавания — силуэты `.face-ph`.
- **Оставлены как есть:** скриншоты сервиса (`dashboard.webp`, `sessions.webp`, `selection.webp`, `parent-*.{png,jpg}`) и встроенный демо-кабинет — это реальный интерфейс продукта.
- Порт: 4323 (`npm run preview`).

## Новые разделы (05.10.2026)

- В шапке и подвале: **Финансы** (`/finance/`), **Безопасность** (`/security/`), **Отзывы** (`/reviews/`).
- С главной убраны и перенесены: блоки «Заказ и деньги» (электронный кошелёк) и «Онлайн-оплата и эквайринг» → `/finance/`; «Безопасность и ответственность» → `/security/`; «Отзывы и кейсы» → `/reviews/`. Блок «У вашей студии свой ритм» с главной удалён.
- `/security/`: блок 1 — безопасность (как был на главной), блок 2 — подтверждающие документы в PDF. Сейчас это заглушки `public/docs/*.pdf` (генератор `work/make-security-docs.py`); утверждённые файлы даёт заказчик — достаточно заменить файлы с теми же именами.
- Меню сворачивается в бургер до 1180px (пунктов стало шесть).
- Страница «Преимущества» (`/benefits/`) удалена вместе со ссылками на неё («Все преимущества», «Подробнее об аналитике», пункт в подвале).
- Порядок главной: первый экран → инструменты → распознавание лиц → дашборд → «Весь съёмочный процесс» → «Настройте процесс» → путь родителя → журнал → форма → финальный призыв.
- Страница «Отзывы» (`/reviews/`, компонент `ReviewsShowcase.astro`, данные `src/content/reviews.ts`): главный кейс крупно (поле `featured`) + карточки историй; карточка открывает окно (нативный `<dialog>`) с задачей, решением, результатом, рассказом и скриншотом сервиса. У каждой истории своя ссылка `#story-<slug>`; закрытие — ✕, Esc, клик по фону, «Назад». На телефоне окно выезжает снизу. Старая карусель `StudioStories.astro` больше нигде не используется.
- Блок «Расчёты и выплаты» на `/finance/` (`AcquiringSection.astro`) переписан по спецификации «Финансы»: оплата поступает в сервис → начисляется процент сервиса, остаток — на баланс компании → автоматическая выплата на расчётный счёт (раз в день/неделю/месяц); руководитель распределяет средства сотрудникам. Тезис «сбор платит родитель» убран со всего сайта (кошелёк, FAQ, документы).
- `/finance/` разведён на два блока без повторов: «Электронный кошелёк» (`MoneyFlow.astro`) — что видно в кабинете: баланс компании, история операций, переводы команде; «Расчёты и выплаты» (`AcquiringSection.astro`) — как деньги попадают на счёт: поступление → процент сервиса и баланс → выплата, плюс настройка периодичности.
- Заголовки h1/h2 уменьшены по всему сайту (h1 ×0.62, h2 ×0.68, минимум 28px; скрипт work/site-v2-headings.py).
- Вертикальные отступы секций сокращены (~×0.6, минимум 32px; скрипт work/site-v2-spacing.py).
